# Humanity.org Website Clone

Exact replica of [Humanity.org](https://www.humanity.org/), inspected with REA and built with high-fidelity design, typography, layout, animations, and downloaded static assets.

## Project Structure

```
humanity-clone/
├── index.html           # Home page ("Verify anything, store nothing")
├── humans.html          # /humans page
├── developers.html      # /developers page
├── enterprises.html     # /enterprises page
├── protocol.html        # /protocol page
├── mission.html         # /mission page
├── ecosystem.html       # /ecosystem page
├── proof-of-trust.html  # /proof-of-trust page
├── contact.html         # /contact page
├── blog.html            # /blog page
├── industries.html      # /industries page
├── use-cases.html       # /use-cases page
├── manifesto.html       # /manifesto page
├── assets/
│   └── images/          # 150+ downloaded high-res logos, icons, graphics
├── server.js            # Zero-dependency local Node.js HTTP server
├── package.json
└── README.md
```

## Running the Clone

1. In terminal, navigate to the `humanity-clone` directory:
   ```bash
   cd humanity-clone
   ```

2. Start the server:
   ```bash
   npm start
   # or
   node server.js
   ```

3. Open your browser at:
   - [http://localhost:3000](http://localhost:3000) (Home)
   - [http://localhost:3000/humans](http://localhost:3000/humans)
